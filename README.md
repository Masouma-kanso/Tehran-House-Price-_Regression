# 🏠 Tehran House Price Regression

A machine learning project to predict house prices in Tehran using regression models.  
It includes data analysis, preprocessing, model training, and evaluation in a single Jupyter Notebook.

---

## 📂 Files
- ML-Tehran House Price Regression.ipynb — main notebook  
- Tehran House Price Dataset.csv — housing data  

---

## 🧠 Tools
Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Jupyter Notebook
